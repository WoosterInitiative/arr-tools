# arr-tools

## Diagnose Movie Path Matches

Compare a movie path with a known existing folder without changing anything:

```bash
uv run arr radarr compare-paths "/data/movies/Guardians of the Galaxy Vol. 2 (2017)" "/data/movies/Guardians of the Galaxy Vol. 2 (2017)"
```

In Git Bash on Windows, prefix the command with `MSYS_NO_PATHCONV=1` to
prevent `/data/...` arguments from being converted to Windows paths.

Omit the second path to rank folders from Radarr (default root `/data/movies/`),
or use `--directory PATH` to scan immediate local subdirectories. `--limit 20`
shows more results. Add `--title "Movie Title" --year 2026` to include the
title/year candidate generated by `fix-all-paths`.

Scores run from 0 to 100 and measure similarity, not match probability.
Raw compares folder names; Normalized ignores case, IMDb IDs and punctuation,
and treats `&` as `and`. Candidate shows the best raw score among generated
candidates. Exact reports the full-path equality used by the repair command,
so even a 100 name score can fail because of a different parent or case.
The output also flags year differences and dotted folder name truncation.
Fuzzy scores are diagnostic only; repairs still use exact equality.
